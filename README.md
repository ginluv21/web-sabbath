# Министерство бесполезных услуг

Учебный проект на React и JavaScript. Тема - каталог абсурдных услуг вымышленного государства, оформление - в стиле старых сайтов и Windows 98.

«Мы создаём проблемы, чтобы вы могли их решить».

## План

- Лабораторная 4: компоненты, props, состояние, собственный хук, алиасы и shared.
- Лабораторная 5: получение услуг через API, загрузка, ошибки и повторный запрос.

## Работа с проектом

Для каждой лабораторной создаётся отдельная ветка: `lab-4`, `lab-5` и далее. После завершения работы открывается Pull Request в `main`. Слияние выполняется вручную, ветки сохраняются.

Инструкции запуска добавим после создания приложения.
